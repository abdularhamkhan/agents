# Planner Agents

This project explores agents that turn a goal into an actionable plan, execute tasks in sequence, and track progress toward completion.

## Focus Areas

- Break larger goals into smaller tasks.
- Order tasks according to dependencies and priorities.
- Track completed, pending, and blocked work.
- Adapt plans when circumstances or requirements change.

## Agent Types

Planner agents are especially related to **Goal-Based** agents because they plan actions to reach a desired outcome. They may also use **Utility-Based** reasoning to compare possible plans and **Learning Agent** techniques to improve planning from experience.

## Example Uses

- Study and learning plans.
- Personal and team workflow automation.
- Project task planning.
- Multi-agent task coordination.
